Vejledning
  1. Opret et nyt Google Sheet
  2. Åbn Udvidelser → Apps Script
  3. Indsæt koden fra apps-script.js
  4. Deploy → Ny implementering → Webapp
  5. Sæt adgang til "Alle" (kun du kender URL'en)
  6. Kopiér URL og indsæt herover
  7. Installér appen: Chrome menu → Tilføj til startskærm
